# Nexmora Tech Website

A responsive one-page company website using the supplied Nexmora Tech logo and a black / gold visual theme.

## Files
- `index.html` — page content and sections
- `styles.css` — responsive layout and styling
- `script.js` — mobile menu, dynamic copyright year, and email-based enquiry form
- `assets/logo.png` — supplied company logo

## Preview locally
Open `index.html` in your browser. For a local development server, you can use the VS Code Live Server extension.

## Before publishing
1. Open `script.js` and replace `hello@nexmoratech.com` with the company's real contact email.
2. Update the service descriptions to match the exact services Nexmora Tech offers.
3. Add real project examples, testimonials, and verified contact/social links if available.
4. Test the form on desktop and mobile. The form opens the visitor's email application; it does not store or send submissions through a backend.
5. Publish the folder using GitHub Pages, Netlify, or Vercel (static site settings; no build command required).

The current content is starter copy because company-specific contact details and confirmed service information were not supplied.
